Accessibility Statement

Last updated: August 3, 2026

Conformance target

We aim to meet WCAG 2.2 Level AA for the Clarity web application and public pages. This is an ongoing goal, not a guarantee of full conformance across every interaction.

Supported interaction modes

  • Keyboard navigation for primary controls, links, and form fields.
  • Visible focus indicators on interactive elements.
  • Text alternatives for essential icons where applicable.
  • Responsive layout for mobile and desktop screen sizes.
  • User-controlled English text input for analysis. Image upload is disabled in this build.

Known limitations

  • Highlighted evidence in analysis results relies on color and underline; pattern labels are also provided in text.
  • On-device OCR quality varies; garbled extraction may affect readability of results.
  • Offline mode depends on prior cache; some assets load only after a first online visit.
  • Full screen-reader and keyboard-only audits have not been completed for every release.

Feedback

Report accessibility barriers through Contact and Corrections. Include the page, browser, and assistive technology you use when possible.
