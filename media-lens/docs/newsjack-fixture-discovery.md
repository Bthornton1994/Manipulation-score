# Newsjack-shaped fixture discovery

Vision check: **Aligns with constraints.** Relevant `VISION.md` sections: "Evidence comes before a score", "Uncertainty must be visible", and "Privacy is the default architecture". This slice maps fixture evidence into `story-discovery.v1`. It does not score outlets, fetch live sources, or enable public display.

Related to #118. Issue #118 stays open.

## What this slice proves with fixtures

`media-lens/worker/discovery/search-provider.js` defines a provider-neutral hit (`title`, `url`, `outlet`, optional `author`, `published_at` or null). Only `fixture` is implemented (`IMPLEMENTED_SEARCH_PROVIDER_MODES`). `host_web_search`, `rss_atom`, and `medialyst` are listed in `PLANNED_SEARCH_PROVIDER_MODES` with status `planned_not_implemented`. `createSearchProvider({ mode })`, `createHostWebSearchProvider`, and `createRssAtomSearchProvider` throw `NOT_IMPLEMENTED` for those modes before any request. `createMedialystSearchProvider` refuses credential fields, and its `search` rejects with `NOT_IMPLEMENTED`. `mapNewsjackEvidenceToStoryDiscovery` also refuses a planned `providerMode`, so mapped output cannot be labeled as a host-search, RSS/Atom, or Medialyst result. The default-off approved-feed client in `discover.js` (PR #155) is a separate path and is not the `rss_atom` search provider. Nothing here reads environment variables or calls a network.

`mapNewsjackEvidenceToStoryDiscovery` stamps `retrieved_at` from the caller. It copies `published_at` only when the value is a UTC ISO timestamp. Otherwise the member keeps `published_at: null`. `coverage_gap` stays `null`. `frames` stays `[]`. `privacy.jev_used` and `privacy.full_text_persisted` stay false.

Cluster basis for this path is `newsjack_cluster_same_public_event`. Newsjack `surfaced` becomes `same_story` with `labeling_basis` `newsjack_relation_surfaced`. `independent_reporting` is used only when `same_story_assessment` is `same_story` and the dated non-wire origin URLs belong to at least two distinct outlets. Two candidates are the same outlet when their normalized outlet names match or their URLs share a registrable domain. Only the first qualifying URL for each outlet is labeled independent (basis `newsjack_origin_distinct_independent_outlets`), so `independent_reporting` has one row per outlet and `independent_outlet_count` equals that row count. Extra qualifying URLs from an outlet already counted stay `same_story` with basis `same_outlet_additional_url`. Two URLs from one outlet, an alias name on the same registrable domain, a `different_story` assessment, a wire or syndicated source, or a missing or unknown outlet do not grant independence. `validateStoryDiscovery` rejects a cluster whose independent rows repeat an outlet name or host. Wire, press-release, and partner URLs use `syndicated` / `wire_press_release_or_partner_url`. A repeated canonical URL uses `syndicated` / `same_canonical_url`. An explicit Newsjack `syndicated` relation uses `newsjack_relation_syndicated`. Any origin assessment other than `same_story` stays `same_story` / `newsjack_origin_uncertain`.

Only public `https` URLs become `canonical_url` links. `classifySourceUrl` uses the worker's `parseArticleUrl` policy, which refuses userinfo, loopback, private, link-local, metadata, and other non-public IP literals (including exotic IPv4 forms), single-label hosts, `localhost`, `*.local`, and the exact metadata hostnames. It also refuses names under `.internal`, `.arpa` (including `.home.arpa`), `.localdomain`, `.lan`, `.intranet`, `.corp`, `.private`, `.test`, `.invalid`, and `.onion`. `.example` stays allowed because it is documentation-only and the fixtures use it. These URLs are never fetched on this path. A refused URL drops the member, so it cannot appear as a link.

Every dropped member is counted on the `sources_checked` row: `rejected_incomplete`, `rejected_non_https_url`, `rejected_non_public_url`, `rejected_different_story`, and `rejected_total`. `rejected_members` lists up to 200 drops with `cluster_id`, `reason`, and `outlet`. It lists no URL, because a refused URL may be non-public.

`createNewsjackAdapter(...).discoverStoryDocument` reads fixture JSON or an operator artifact directory (`clustered_candidates.json` or `cluster.json`, plus `origin_findings.json` or `story_origin.json`). A missing directory, a missing `artifactsDir`, or a failed directory read returns `status: abstain`, `reason: artifacts_unavailable`, and `sources_checked[].outcome: failed` with a non-null `error`. A readable directory with no matching artifact files uses `outcome: artifacts_read`, `error: null`, and `reason: no_usable_members`. A matching artifact (or a fixture file) that is not valid JSON, has an unexpected top-level type, or has a cluster whose `members` is not an array returns `status: abstain`, `reason: artifacts_invalid`, `outcome: failed`, `error: artifact_json_invalid` or `artifact_shape_invalid`, and `error_file`. A parse problem never escapes as an exception. Individual member records that are not objects are counted as incomplete. `cli` mode still throws. `getStoryContext` is unchanged. `GET /stories` is unchanged and stays default-off.

## Still unverified (needs a live provider and a rights decision)

- Host web search and RSS/Atom search are not implemented. Their modes are planned only and fail with `NOT_IMPLEMENTED`. No search was run and no feed was fetched.
- Medialyst account, terms, credentials, SDK, and credit spend are not implemented.
- Whether Media Lens may store or show third-party titles, canonical URLs, and publication times from host search or named feeds.
- Real Newsjack `published_at` recovery, cluster quality, and origin corroboration on live pages.
- `data_origin: "newsjack_artifacts"` is emitted for the artifact read path. The story-discovery validator allows it today because it does not enumerate `data_origin`. Treating it as a production source label still needs an owner note.
- Public `/stories` display, source approval, retention of `latestDiscovery`, and ml-jev proxying. Those remain the decisions in `docs/media-lens-story-discovery-owner-decisions.md`.

Do not describe fixture passes as live coverage or as Medialyst-grade freshness.
